 # Green Bikes Website

   This repository contains the website of **Green Bikes**, a fictional company that rents electric and mountain bikes in the city centre.

   ## Technologies used
   - HTML
   - CSS

   ## How to open the website

   1. Download or clone this repository.
   2. Open the file `index.html` in your web browser (double-click it, or right-click > Open with > your browser).
